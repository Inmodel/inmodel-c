# User Experience Principles

The best Web3 apps feel like Web2 apps.

### 1. Speed and Responsiveness
- **Fast Loading:** Use skeleton screens while fetching data from the blockchain.
- **Optimistic Updates:** Update the UI before the transaction is finalized (but show it as "Pending").

### 2. Clarity Over Jargon
- **Translate Web3:** Instead of "Sign Instruction," say "Verify your Repo." Instead of "PDA Address," say "Project ID."
- **Helpful Errors:** If a transaction fails because of rent, explain it as "Your wallet needs a small amount of SOL to store this data."

### 3. Visual Feedback
- **Wallet Connection:** Show the connected address and balance clearly.
- **Progress Indicators:** Use spinners or progress bars for the GitHub analysis phase.
- **Success States:** Celebrate when a score is successfully recorded on-chain.
