# Hackathon Strategy

Hackathons are about **Speed, Clarity, and Impact.**

### 1. The 2-Minute Pitch
Your project will be judged in roughly 2 minutes. Your UI should make the "Magic Moment" clear immediately.

### 2. The Demo Loop
1. **Connect Wallet:** Make it seamless.
2. **Submit Repo:** Show real-time progress.
3. **Get Score:** Provide a satisfying "reveal" moment.
4. **On-Chain Proof:** Show the Solscan link.

### 3. Judges' Checklist
- **Functionality:** Does it actually work on Devnet?
- **Creativity:** Is this a new way to solve a problem?
- **Practicality:** Can this be used in the real world?
- **Polish:** Is the UI clean and bug-free?
