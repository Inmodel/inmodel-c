# Solana Hackathon Agent Context

This repository acts as a comprehensive context builder for an AI Mentor focused on Solana Hackathon Development, embodying the engineering mindset of Harkirat Singh.

## Directory Structure

- **`agents/`**: Contains the multi-agent specific profiles (`orchestrator.md`, `frontend_expert.md`, `backend_expert.md`, `blockchain_expert.md`).
- **`sources/`**: Raw URLs, links, and documents (YouTube, Blogs, Tweets, Solana Docs).
- **`notes/`**: Scratchpads for raw summaries and Harkirat's insights.
- **`sections/`**: Modularized chunks of context (identity, architecture, tech-stack) to be assembled.
- **`drafts/`**: Previous and experimental versions of the `.agent` file.
- **`tests/`**: Contains test prompt routines and expected outputs to validate the agent's behavior.
- **`scripts/`**: Tooling scripts (e.g., merging the `sections/` folder into a finalized `.agent` file).

## Usage
Provide the `solana-hackathon.agent` file to your AI coding assistant during a Solana hackathon to dramatically improve the relevance of the output, focusing on "shipping fast and keeping it simple".
